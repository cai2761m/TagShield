# TagShield 验收记录

日期：2026-09-27。环境：Windows、Node.js 24.19.0、Microsoft Edge headless。

## 已执行的验证

- `npm run check`：TypeScript strict、ESLint、60 个单元/事务/磁盘持久化测试、生产构建全部通过。
- `npm run test:browser`：真实 CodeMirror 6 编辑器及本项目实际审查/对比/历史 UI；Obsidian 容器使用测试替身。
- `node scripts/benchmark.mjs`：10,000 段、约 329,000 字符的笔记，初次解析约 265ms，单次插入的增量解析约 20ms，附近候选检查约 14ms（只得到 3 个候选），用户显式全文扫描约 121ms。单次本机测量，随机器和文档结构变化。
- `npm audit`：依赖升级后 0 个已知漏洞。
- 桌面 1280×900 和窄屏 390×844 的弹窗截图已检查，没有横向溢出或按钮截断。截图输出至 `test-results/`。

## 覆盖内容

1. 规格中的粗体正文修复；代码围栏、缩进代码、行内代码、YAML（含未闭合）、HTML block、行内成对 HTML、链接等保护。
2. 远距离配对 HTML、HTML 容器内部标签、属性内尖括号、带反引号的代码样式；重复修复幂等。
3. 笔记禁用、区域 off/on、忽略下一行、映射单实例忽略、忽略标签类型、literal 明确文字标记。
4. 修改前持久化并回读校验；历史写入失败时不修改。写入期间继续输入、切换笔记或卸载时取消过期操作。原始变更日志不可变，状态存于独立文件；状态写入中断不会损坏恢复数据。
5. 真实 CodeMirror Undo/Redo、独立撤销边界；撤销后不立即自动修复。
6. 保存后创建新的 HistoryManager / 编辑器对象并回滚；另有真实临时磁盘文件读取验证，不依赖同一内存实例。
7. 原位置偏移后通过唯一上下文恢复；上下文改变、重复匹配、已撤销内容和重叠编辑拒绝恢复。
8. 冲突预览不会写入；强制恢复必须勾选确认，恢复前保存当前内容的新快照。
9. Safe 模式打开/输入不自动写入，Manual 不生成实时提示，Automatic 在编辑明确标记行时才运行；IME 组词期间保持原文。
10. 预览后继续编辑会使原预览失效，拒绝覆盖新输入。

## 规格取舍

- HTMLBlock 的绝对保护优先于单行 `<Component>` 的 ambiguous 示例。
- 自动模式额外要求 `<!-- tagshield: literal -->` 明确意图；自然语言判断只用于建议。
- 「保存历史」固定开启，不提供会破坏安全保障的关闭选项。
- 一次「忽略此项」为当前编辑器会话状态；需要永久忽略时使用持久注释或类型设置。
- 多行复杂 JSX/泛型不做语义猜测。文件重命名后不自动迁移旧历史路径。
